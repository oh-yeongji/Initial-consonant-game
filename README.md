# Ja-eum-nol-i(자음놀이)

실시간으로 2인이서 랜덤으로 제시된 초성에 맞는 단어를 제한된 시간안에 상대방보다 많이 입력하면 이기는 게임입니다.

## 기능

- 시작화면을 1990년대 컴퓨터 화면으로 구성하여 하단에 taskbar로 오른쪽에 시계를 배치하고 왼쪽에 시작버튼을 배치하여 마치 게임을 설치한것같은 표현을 하여 하나의 재미로 보이게끔 함.
  방 들어가기 클릭 시 규칙 장 나옴 , 규칙창 15초 후 사라짐 기능 . 다시보지않기. 확인 누르면 없어짐.
- 닉네임 설정창 (2~8자 안) , 중복검사 통과전 설정버튼 비활성화 중복검사통과후 설정 활성화
- 설정 클릭 후 대기룸으로 이동. 먼저 입장한 사람이 방장으로 위임
  [방장] 표식과 본인의 닉네임 옆 (당신) 표시
- 방장 레디 버튼을 누르고도 10초간 다른 유저가 누르지않을시 강제 시작버튼 활성화
- 방장이 강제 시작한 경우에는 강제 시작 취소 가능. Esc 연동
- 하지만 유저 둘다 레디 버튼을 눌렀을 경우 는 강제 취소 불가능
- 방장이 레디버튼을 눌렀을때는 READY? ->GAME START
- 방장이 아닌유저가 레디버튼을 눌렀을때는 READY? ->READY! 로 나타내어 소소한 재미를 주었습니다.
- 유저가 혼자 입장했을때는 레디버튼을 비활성화되게 하였습니다.
- 방장은 게임 제한 시간을 30, 60 ,90 ,120 초 중에 선택할수있고 기본은 60초로 설정되어있습니다. 한판의 시간 변경 횟수는 3회로 제한 하였고 방장이 위임되도 횟수도 그대로 위임받게하였습니다. 시간을 변경하면 시스템 메시지로 모두에게 알렸습니다.
- 방장이 아닌유저는 시간설정을 할수없음을 방장전용으로 알렸습니다.
- 유저가 입장하면 모두에게 유저가 입장하였습니다 라고 알리게 설정하였습니다.
- 퇴장할때도 유저가 퇴장했다고 알림.
- 게임에서 유저와 매칭되기전 지루함을 줄여주고 유저끼리 긴장을 풀고 친목을 도모하기위한 대기실과 채팅을 만들었습니다.
- 채팅에 자동 스크롤 기능 추가
- 게임이 시작되기전에 곧 게임이 시작됨을 모달창으로 알리고 게임시작까지 남은시간 3초를 초록색과 빨간색을 이용하여 두근거리는 효과와 빛이 번쩍거리는 효과로 레트로 감성을 살려 향수와 긴장감을 불러일으기케 했음.
- 게임방에서는 타이머로 남은 시간을 알려줬고 MM:SS 형식으로 1초 씩 내리며 긴장감을 불러일으켰음.
- 게임방에서 게임시작 오버레이가 잠깐 뜨면서 화면을 보고있지않던 유저들도 인지할수있도록 한다.
- 본인을 왼쪽에 위치시켜고 밑에 입력창을 길게 배치하여 가시성을 높였고 입력한 단어가 맞으면 자신의 단어창에 바로 나타나고 맞지않으면 맞지않는 이유를 알려주었음. 상대방이 입력했던 단어를 입력해도 통과 안됨.
- 게임시간이 다되면 바로 게임 끝을 오버레이와알리며 입력창을 막음
- 그리고 결과 창에서 게임 결과를 나타내고 나와 상대방이 입력한 단어와 뜻을 알수있도록 하였음
- 위에 승자와 패자라는 직접적인 단어대신 loser와 winner 로 완곡한표현을 하였음
- 게임중에서 한 유저가 나가면 그 즉시 기권패 처리 되어 남은유저의 단어갯수에 상관없이 승리가 되고 남은유저의 승리가 뜻깊은 승리로 보이게 끈기있는 대결을 통해 이겼다고 표현
- 둘이 동율일때는 패자를 찾지못했다는 표현을 이용해 승리 하지못했다는 아쉬움을 낮추게끔 하였음.
- 결과창이 나오고 15초 후에 다시 시작화면으로 돌아가기때문에 원래 속해있던 게임방의 데이터를 빨리 없앨수있고 다시하기를 누르면 한명만 있는 대기룸으로 가거나 없으면 새로운 방을 만들어서 보내게끔 하였고 방에 두명다 없으면 데이터를 삭제하여 데이터 아낌.

# Ja-eum-nol-i (자음놀이)

실시간으로 2인이서 랜덤으로 제시된 초성에 맞는 단어를 제한된 시간 안에 상대방보다 많이 입력하면 이기는 게임입니다.

📌 주요 기능

1. UI/UX 및 레트로 콘셉트
   1990년대 OS 스타일 UI: 하단 작업 표시줄, 시계, 시작 버튼 등을 배치하여 고전 게임을 설치하고 실행하는 듯한 레트로 감성을 구현했습니다.

규칙 안내 모달: 처음 입장 시 15초 후 자동으로 사라지는 규칙창을 띄우며, '다시 보지 않기' 기능을 지원하여 피로도를 줄였습니다.

2. 대기실 및 실시간 채팅
   닉네임 설정: 2~8자 이내로 설정 가능하며, 중복 검사를 통과해야만 설정 버튼이 활성화됩니다.

대기실 채팅: 게임 매칭 전 지루함을 줄일 수 있도록 실시간 채팅(자동 스크롤 지원)을 제공합니다.

시스템 알림: 유저의 입장/퇴장 및 방장의 설정 변경 사항을 시스템 메시지로 모두에게 즉각 안내합니다.

3. 방장 시스템 및 게임 준비 상태 관리
   권한 위임: 먼저 입장한 유저에게 방장 권한이 부여되며, 닉네임 옆에 방장 표식 및 본인 식별(당신) 표식이 제공됩니다.

게임 시간 설정 (방장 전용): 30, 60(기본), 90, 120초 중 선택 가능합니다. 한 판당 시간 변경은 3회로 제한되며, 방장 권한 위임 시 남은 횟수도 함께 인계됩니다. 비방장에게는 방장 전용 기능임을 UI로 안내합니다.

Ready 및 강제 시작 로직:

혼자 입장한 상태에서는 Ready 버튼이 비활성화됩니다.

버튼 텍스트 차별화: 방장은 READY? -> GAME START, 비방장은 READY? -> READY!로 변경되어 소소한 재미를 줍니다.

방장이 Ready를 누른 후 상대방이 10초간 누르지 않으면 '강제 시작' 버튼이 활성화됩니다 (ESC 키로 강제 시작 취소 가능). 단, 양측 모두 Ready 상태일 때는 강제 취소가 불가능합니다.

4. 인게임 플레이
   시작 카운트다운: 게임 시작 3초 전, 초록색/빨간색 점멸 효과가 있는 모달창을 띄워 레트로한 감성과 긴장감을 연출했습니다.

게임 UI: 화면을 보지 않던 유저도 인지할 수 있도록 시작 오버레이를 제공하며, 좌측에 본인 영역, 하단에 넓은 입력창을 배치하여 가시성을 높였습니다.

단어 검증 시스템: 입력한 단어가 정답이면 즉시 화면에 렌더링되고, 오답이거나 상대방이 이미 입력한 단어일 경우 실패 사유를 정확히 안내합니다.

타이머: MM:SS 형식으로 1초씩 줄어드는 타이머를 배치했습니다. 시간이 다 되면 즉시 게임 종료 오버레이가 뜨며 입력창이 차단됩니다.

기권승 처리: 게임 도중 상대방이 퇴장할 경우 즉시 기권승으로 처리되며, 끈기 있는 대결을 통해 얻어낸 뜻깊은 승리임을 안내합니다.

5. 게임 결과 및 세션 최적화
   결과창 제공: 나와 상대방이 입력한 단어들의 목록과 뜻을 함께 보여줍니다.

UX를 고려한 문구: 직설적인 승패 단어 대신 Winner/Loser로 완곡하게 표현했으며, 동점일 경우 "패자를 찾지 못했다"는 문구로 아쉬움을 달래도록 했습니다.

세션 정리: 결과창 출력 15초 후 시작 화면으로 자동 복귀시켜 기존 방 데이터를 빠르게 소멸시킵니다.

다시 하기: '다시 하기' 클릭 시 1명만 있는 대기룸으로 매칭시켜 주거나 새 방을 생성하며, 방에 아무도 남지 않으면 즉시 데이터를 삭제하여 서버 메모리를 아끼도록 최적화했습니다.
